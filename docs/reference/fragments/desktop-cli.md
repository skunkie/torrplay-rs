## Command-line options {#options}

The desktop executable, `torrplay-desktop`, takes these options. A torrent
file or magnet URI opens the add page. Use the separate `torrplay`
executable for the administration and MCP commands.

## CLI commands {#commands}

Stop TorrPlay before setting a password, removing a password, or working
with backups. Pass the application's data directory to the CLI with
`--data-dir` if you changed it.
